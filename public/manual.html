환불 · 반품 · 적립금 처리 매뉴얼

화면의 버튼 이름을 그대로 표기했습니다 · 2026년 7월 21일 기준

기본

먼저 이해할 4가지 — 이것만 알아도 절반

원칙 1환불과 반품은 다른 메뉴

환불 = 돈만 (정산관리 탭) · 반품 = 물건 회수 + 재고 복구 (보관/반품 탭). 둘 다 필요하면 반품 먼저 → 환불.

원칙 2환불은 2단계

직원이 신청 → 대표가 정산관리에서 승인해야 실제 처리. 신청만으로는 돈·재고·적립금 아무것도 안 바뀝니다.

원칙 3적립금 자동 적립 없음

구매 시 % 적립 기능은 없습니다. 대표가 정산관리에서 전부 수동으로 지급·회수합니다.

원칙 4권한 구분

출고완료/취소·환불 승인·반품 삭제·주문취소는 대표(관리자)만. 포장 담당자에게 주문입력·정산관리 탭이 안 보이는 건 정상.

상황 1

고객이 "환불해 주세요" — 물건 회수 없이 돈만

직원 — 환불 신청

  1. 주문 찾기: 주문현황 탭에서 검색, 또는 대시보드 탭의 출고완료+입금완료 주문에서 💸 환불신청 클릭
  2. 환불 방식 선택: 💵 현금환불 또는 🪙 적립금환불
  3. 현금환불이면 🏦 환불 계좌 입력 (은행명 / 예금주 / 계좌번호) — 고객에게 꼭 확인
  4. 범위 선택: 전액환불 / 부분환불 · 금액은 입금액 초과 불가 · 사유 입력 (단순변심 / 불량 / 오배송 등)
  5. N원 환불 신청 버튼 → 주문이 환불신청 상태로 바뀜. 대표에게 알려주세요.

대표 — 승인 또는 반려

  1. 정산관리 탭 → 상단 필터 환불신청 (대기 건수 표시)
  2. 주문 클릭 → 환불 신청 · 승인 대기 카드에서 방식·금액·계좌·사유 확인 (계좌는 복사 버튼)
  3. 현금 환불 또는 적립금 전환 → 확인창에서 승인
  4. 잘못된 신청이면 ✗ 반려 → 입금완료로 복귀, 사유는 담당자 메모에 기록
주의

현금환불 승인은 기록만 남깁니다. 실제 은행 이체는 앱 밖에서 직접 해야 합니다.

승인하면 자동으로 되는 것

항목전액환불부분환불
환불 기록 남김OO
고객이 썼던 적립금 자동 반환OX — 반환 안 됨
무료배송권 1장 복원OX
합배송 그룹에서 제외OO

가장 많이 헷갈리는 지점

"부분환불 했는데 고객 적립금이 안 돌아왔어요" → 정상 동작입니다. 전액환불일 때만 자동 반환됩니다. 부분환불에서 돌려줘야 하면 대표가 적립금 관리에서 수동 등록하세요 (상황 5).

상황 2

고객이 물건을 돌려보냄 — 반품

등록

  1. 보관/반품 탭 → 반품 서브탭 → "반품 등록"에서 주문 검색 (출고완료 주문만 검색됨 · 대시보드의 ↩️ 반품 신청 버튼도 가능)
  2. 품목별 반품 수량 입력 — 부분 반품 가능, 전량 버튼 있음. 금액은 수량 비율로 자동 계산
  3. ↩️ 반품 신청 등록 클릭

상태 진행 — 버튼을 순서대로

반품신청→🚚 수거중으로→수거중→📥 반품입고 (재고 복구)→반품입고→✓ 완료 / 🔄 교환 / 💸 환불신청 연결
자동 처리

📥 반품입고 (재고 복구)를 누르는 순간 재고가 자동 복구되고 입출고 로그에 기록됩니다. 이 버튼을 안 누르면 재고는 안 돌아옵니다.

주의
  • 확인창에 "재고 미등록 N건은 복구 없이 진행"이 뜨면 그 품목은 재고현황에서 수동 보정 필요
  • "⚠ 재고 복구 실패 N건" 알림이 뜨면 재시도해도 복구되지 않습니다 — 바로 수동 보정하세요
  • 반품 건 삭제(대표만)를 해도 이미 복구된 재고는 되돌아가지 않습니다

반품입고 후 마무리 3가지

  • ✓ 완료 — 물건만 돌려받고 끝 (돈 문제 없음)
  • 🔄 교환 — 상황 4 참고
  • 💸 환불신청 연결 — 돈도 돌려줘야 하면 여기로 → 상황 1의 대표 승인 절차로
상황 3

반품 + 환불 둘 다 — 가장 흔한 케이스

순서를 꼭 지키세요:

  1. 반품 등록 → 수거중 → 📥 반품입고 (재고 복구) — 재고 먼저!
  2. 💸 환불신청 연결로 환불 신청
  3. 대표가 정산관리에서 승인
순서를 건너뛰면

정산관리에서 환불만 처리하면 돈은 나가는데 재고는 안 돌아옵니다. 환불 기능은 재고를 건드리지 않기 때문입니다.

상황 4

교환

  1. 반품 흐름으로 반품입고까지 진행 (기존 물건 재고 복구)
  2. 🔄 교환 버튼 → 교환 보낼 품목과 차액 입력
  3. 차액 처리:
    • 고객이 더 내야 하면(+) → 원 주문에 미수금으로 잡히거나 적립금에서 차감
    • 고객에게 돌려줘야 하면(−) → 환불신청으로 연결 → 대표 승인
상황 5

적립금 지급 · 회수 — 대표 전용

다시 강조

자동 적립은 없습니다. 적립금이 늘어나는 경우는 ① 대표 수동 지급 ② 환불의 적립금 전환 ③ 전액환불·주문삭제 시 자동 반환 — 이 세 가지뿐입니다.

지급

  1. 정산관리 탭 → 🎁 적립금 & 배송권 관리 서브탭
  2. "혜택 발급" 카드에서 💰 적립금 선택 (무료배송권도 같은 곳)
  3. 고객명 검색·선택 → 금액·사유 입력 → 적립금 등록

회수

같은 화면의 회수 버튼 → "N님의 적립금 M원을 회수하시겠습니까? 잔액 A원 → B원" 확인 후 진행.

주의
  • 고객관리에 등록된 고객만 가능 — "등록되지 않은 고객입니다"가 뜨면 고객관리에서 먼저 등록
  • 적립금은 고객 이름 글자 그대로 매칭됩니다. 닉네임·공백이 다르면 잔액이 딴 사람처럼 분리됨 → 이름 표기 통일 필수

내역 확인: 같은 화면 아래 "적립금 내역" — 전체/적립/사용 필터, 고객 검색, 10건씩 표시. 무료배송권 보유 현황 표도 그 아래에 있습니다.

상황 6

적립금 사용 — 주문에서 차감

방법 A — 새 주문 받을 때 (주문입력 탭)

주문입력 폼에서 적립금 사용액 지정. 잔액·주문총액 한도 내에서 자동 조정됩니다. 이미 완납으로 들어가는 주문(방문 결제 등)에는 적용되지 않습니다 — "이미 완납 주문이라 적립금은 적용하지 않았습니다".

방법 B — 기존 주문의 미수금 처리 (정산관리 탭)

주문 선택 → 적립금 차감 (미수금이 있는 주문에만 보임 · "차감 가능: 최대 N원" 안내). 잔액 초과·미수금 초과는 불가.

최소 사용 금액 제한은 없습니다.

상황 7

실수했을 때 되돌리기

실수되돌리는 방법권한
환불 신청을 잘못 올림정산관리에서 ✗ 반려 → 입금완료로 복귀대표
환불을 잘못 승인함정산관리에서 환불 취소 — 전환·복원된 적립금도 함께 정리됨대표
출고완료를 잘못 누름출고 취소 → 재고 복구 + 출고 로그 삭제대표
주문 자체를 없던 일로대시보드의 주문취소 — 결제·출고·적립금 로그 전부 삭제, 복구 불가. 최후의 수단대표
금지

절대 하지 말 것

  1. Supabase(DB)에서 데이터 직접 수정 금지. 화면의 결제상태는 컬럼이 아니라 결제 로그 합산으로 계산됩니다. DB에서 컬럼만 고치면 화면과 데이터가 어긋나고, 적립금도 한 줄만 지우면 잔액이 틀어집니다.
  2. 부분환불 후 적립금·배송권이 안 돌아온 것을 버그로 착각하고 임의 조작 금지 — 정상 동작입니다. 필요 시 수동 지급.
  3. 엑셀 업로드 주문(시간이 00:00으로 표시)은 임의 수정 금지 — 대시보드 집계 전용이라 건드리면 매출이 틀어집니다.
  4. 주문 삭제 시 "적립금 N원 반환 실패 — 정산관리에서 직접 등록해주세요" 알림이 뜨면 그 자리에서 바로 수동 등록 (나중에 하면 잊어버립니다).
FAQ

자주 묻는 질문 — 직원 오해 TOP 5

Q1. 환불신청 했는데 왜 처리가 안 되나요?
신청은 요청일 뿐입니다. 대표가 정산관리에서 승인해야 처리됩니다.
Q2. 부분환불 했는데 고객이 쓴 적립금이 안 돌아와요.
정상입니다. 전액환불일 때만 자동 반환됩니다. 필요하면 대표가 수동 지급하세요.
Q3. 환불 처리했는데 재고가 안 늘어요.
환불은 재고를 건드리지 않습니다. 물건을 받았으면 반품 흐름(반품입고)을 쓰세요.
Q4. 적립금 등록이 안 돼요 — "등록되지 않은 고객입니다".
고객관리에 먼저 등록하고, 이름 표기가 주문의 고객명과 정확히 같은지 확인하세요.
Q5. 환불했더니 미수금 표시가 사라졌어요.
정상입니다. 환불은 가격 조정으로 취급되어 미수금이 0으로 계산됩니다.
실습

신입 교육용 시나리오 — 인수인계 시 이 순서로

  1. 환불만 — 테스트 주문 하나로 부분환불 5,000원 신청 → 대표 계정으로 반려까지 해보기
  2. 반품+환불 — 반품 등록 → 수거중 → 반품입고(재고 숫자가 변하는 것 직접 확인) → 환불신청 연결 → 승인
  3. 적립금 — 테스트 고객에게 3,000원 지급 → 적립금 내역에서 확인 → 회수
  4. 마지막 질문: "부분환불하면 적립금이 자동 반환되나요?" (답: 아니오) — 이해도 체크
